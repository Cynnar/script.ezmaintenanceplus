* **Python 3 Native:** Codebase updated to require a minimum of Python 3.
* **Kodi 21+ Optimized:** Designed specifically for Kodi Omega and newer releases.
* **Performance:** Background service rewritten to reduce CPU usage and eliminate startup lag.
* **Modern Tools:**
    * New lightweight Speedtest implementation (removed legacy dependencies).
    * Fixed Log Viewer (Unicode support & Private Pastebin uploads).
    * Updated Advanced Settings XML generation for modern buffer tags.
    * Refactored Backup/Restore logic for better stability.
